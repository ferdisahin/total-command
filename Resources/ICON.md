# Application icon

The red floppy-disk design was generated with OpenAI ImageGen and selected by the project owner on 2026-10-20. AppIcon.png is the master image; AppIcon.icns contains the macOS icon representations. Both are distributed under the repository GPL-3.0-only license.

To regenerate the ICNS with Pillow: `Image.open("Resources/AppIcon.png").save("Resources/AppIcon.icns", format="ICNS")`. Pillow is only needed for regeneration, not normal builds.
